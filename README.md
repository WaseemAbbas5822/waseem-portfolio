# Waseem Abbas Portfolio (React + Vite)

    npm install
    npm run dev       # development
    npm run build     # production build in /dist

- All content is in `src/data.js` (projects, skills, services, links).
- Add `public/photo.jpg` and `public/resume.pdf`.
- Deploy: push to GitHub, then import the repo in Netlify or Vercel (build: `npm run build`, output: `dist`).
